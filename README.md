One image that sums up the world's news of Wednesday, 25 November 2026:
39 stories across 9 regions, drawn as a newspaper front page — masthead,
numbers strip, three illustrated top stories (two tankers hit mines in the
Strait of Hormuz; Pakistan's first astronaut boards China's Tiangong station;
Houthis claim a strike on Saudi Arabia's Ras Tanura refinery), a world map
with pins, a UTC timeline, and a 36-story grid, each with its named outlet.
Every story happened or was first reported on 25 November 2026, each verified
against at least two independent sources; claims are attributed to their
claimants, with no invented numbers, quotes or sources.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
# writes out/entry.png (1024x1024 PNG, under 1 MiB, byte-identical every run)
```

`main.py` is a copy-only program (Python 3.13, standard library only): it
copies the pre-drawn `entry.png` in this repository to
`$MAKEFUN_OUTPUT_DIR/entry.png`. It needs no network and writes the same
bytes on every run.
